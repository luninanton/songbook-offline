# Holychords Офлайн

Личное Android-приложение: база христианских песен с аккордами, полностью офлайн,
с транспонированием тональности. Источник данных — публичные страницы
[holychords.pro](https://holychords.pro/).

> **Назначение:** личное использование, без публикации в Google Play.
> Тексты и аккорды песен — охраняемые произведения. Перед любой публикацией
> требуется разрешение правообладателей и/или администрации сайта.

## Что уже есть (текущий этап)

| Этап | Содержание | Статус |
|---|---|---|
| M0 | Каркас репозитория, Android SDK, сборка APK | готово |
| M1 | Краулер + парсер (`--lang=ru`), QA на 500 песнях | готово |
| M2 | Полная база: 43 058 песен, SQLite + FTS4, архив, manifest | готово |
| M3 | Движок транспонирования + 44 теста + инвариант на всей базе | готово |
| M4 | Экраны: поиск, песня, настройки; планшетный режим | готово |
| M5 | APK с базой внутри, копирование базы при первом запуске | готово (проверено на эмуляторе) |
| M6 | Онлайн-обновление: дельта-пакеты, GitHub Releases, новые песни с сайта | код готов |
| M7 | Приёмка | в работе |

## Требования к окружению

- Node.js 20+
- JDK 17
- Android SDK (cmdline-tools, platform-tools, platforms;android-35, build-tools;35.0.0)
  - `ANDROID_HOME` должен указывать на каталог SDK

## Команды

```bash
npm install          # зависимости
npm run dev          # разработка в браузере (http://localhost:5173)
npm run typecheck    # проверка типов
npm test             # юнит-тесты (vitest)
npm run build        # сборка web-части в dist/

npm run android:sync # собрать web + скопировать в android/
npm run android:apk  # debug APK: android/app/build/outputs/apk/debug/app-debug.apk

npm run crawl        # обход сайта (M1)
npm run db:build     # сборка songs.db (M2)
```

## Структура

```
src/core/    общий код: парсер страницы, транспонирование, модель данных
src/ui/      экраны приложения (без тяжёлого фреймворка)
src/styles/  вёрстка, адаптив под телефон/планшет
scripts/     краулер, сборка базы, публикация дельта-пакетов
data/        сырые данные и собранная база (в git не попадают)
android/     проект Capacitor (minSdk 23, targetSdk 35)
docs/        план и решения
```
