# Установка и проверка

## 1. Установка APK

APK — `android/app/build/outputs/apk/debug/app-debug.apk` (~60 МБ, база песен внутри).

1. Скопировать файл на телефон (кабель, Telegram «Избранное», облако — как удобно).
2. Открыть файл в проводнике телефона.
3. Разрешить установку из этого источника, если система спросит.
4. Запустить «Holychords Офлайн».

Первый запуск: приложение копирует базу из APK во внутреннее хранилище
(~142 МБ, 3–8 секунд, экран при этом показывает заставку). Дальше всё работает
без интернета — сеть нужна только для явного обновления базы.

Требования: Android 6.0 (2015 г.) и новее, ~250 МБ свободного места.
Подпись — debug (личное использование). Для нормальной установки на телефон
без предупреждений нужен release-ключ (см. ниже).

## 2. Чек-лист приёмки (5 минут)

| Проверка | Как | Ожидание |
|---|---|---|
| Офлайн-старт | включить авиарежим, открыть приложение | список песен открывается, в шапке «43 058 песен · 2026-10-26» |
| Поиск по названию | ввести слово из названия | находятся совпадения за < 100 мс |
| Поиск по словам | ввести фразу из текста | находит песню (поиск по тексту через FTS) |
| Поиск без «ё» | «елка» вместо «ёлка» | находит (нормализация ё→е для названий/исполнителей) |
| Тональность | открыть песню, нажать `+` | аккорды поднялись на полутон, подпись тональности изменилась |
| Возврат | нажать «сброс» в сетке тональностей | текст совпадает с исходным |
| Капо | выбрать капо +2 | аккорды опустились на 2 полутона, тональность песни прежняя |
| Колонки/шрифт | A+ / повернуть экран | ничего не теряется, транспозиция сохраняется |
| Избранное | звезда на песне → вкладка «Избранное» | песня в списке, после перезапуска остаётся |
| Обновление | Настройки → Проверить обновления | «База уже актуальна» либо предложение обновиться |

## 3. Планшет

Проверить то же самое в ландшафте: список слева, песня справа, аккорды не
обрезаются, панель транспонирования доступна без прокрутки.

## 4. Release-сборка (подписана, ставится без предупреждений)

Ключ уже создан: `android/holychords-release.keystore`, параметры — `android/keystore.properties`
(оба файла в `.gitignore`). Сертификат: `CN=Songbook Offline`.

```bash
npm run android:apk:release        # web + cap sync + gradle assembleRelease
# результат: android/app/build/outputs/apk/release/app-release.apk
```

### ⚠️ Резервная копия ключа — обязательна

Пароль к ключу лежит в `android/keystore.properties`. Если потерять keystore или пароль,
обновить уже установленное приложение будет невозможно — придётся удалять его и ставить заново.

Сделай копию (в защищённое место, не в git):

```bash
mkdir -p ~/Documents/backup-songbook
cp android/holychords-release.keystore android/keystore.properties ~/Documents/backup-songbook/
```

### Важно про переход с debug на release

Подписи debug и release несовместимы: приложение нужно один раз удалить и поставить
release-версию. База песен лежит внутри APK, поэтому данные не теряются — но избранное
и настройки (они в локальном хранилище приложения) сбросятся.

Проверить подпись:

```bash
$ANDROID_HOME/build-tools/34.0.0/apksigner verify --print-certs \
  android/app/build/outputs/apk/release/app-release.apk
```

## 5. Бэкап исходных данных

Базу и снимки стоит хранить отдельно от репозитория (они не в git):

```bash
cp data/build/songs.db data/raw/ru.jsonl ~/Documents/backup-songbook/
```
