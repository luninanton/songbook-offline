# Обновление базы (M6)

Два независимых режима — оба запускаются вручную из «Настройки → Обновление».

## 1. Новые песни прямо с сайта

Кнопка «Новые песни с сайта»:

1. приложение читает `/lang/2?page=1..2` и собирает id;
2. берёт id больше максимального id в базе (нумерация на сайте возрастающая);
3. скачивает 10–20 страниц песен, парсит тем же парсером (`src/core/parser.ts`), что и краулер;
4. добавляет их в SQLite и перестраивает FTS-индекс.

Плюс: работает без публикации пакетов. Минус: не подхватывает правки в старых песнях.

## 2. Обновление из GitHub Releases

### Как выпустить обновление

```bash
# 1. Обновить базу (полный обход или инкремент)
npm run crawl -- --lang=ru
npm run db:build -- --in=data/raw/ru.jsonl --version=2026-11-01

# 2. Собрать дельту от предыдущей версии
npm run delta:build -- \
  --old=data/raw/ru-2026-10-26.jsonl \
  --new=data/raw/ru.jsonl \
  --from=2026-10-26 --to=2026-11-01 \
  --base-url=https://github.com/USER/holychords-offline/releases/download/v2026-11-01

# 3. Опубликовать (нужен gh auth login или GH_TOKEN)
npm run release:publish -- --version=2026-11-01 --repo=USER/holychords-offline
```

В релиз попадают три файла: `songs.db.gz` (полная база), `delta-<версия>.json.gz`
(только изменения) и `manifest.json`.

### Что делает приложение

1. читает manifest (по URL из настроек);
2. `planUpdate(localVersion, manifest)` решает: актуально / дельта / нужна полная база;
3. скачивает дельту, проверяет **sha256**, распаковывает gzip;
4. применяет пакет одной транзакцией (`executeSet`), перестраивает FTS4, обновляет `meta`.

Если дельта собрана от другой версии (пропустили релиз), приложение честно скажет,
что нужна полная база, — молча применять несовместимую дельту нельзя.

## Технические решения

| Решение | Почему |
|---|---|
| `INSERT OR REPLACE` вместо `UPSERT` | на Android 6.0 системный SQLite старше `ON CONFLICT DO UPDATE` |
| FTS4 + `INSERT INTO songs_fts(songs_fts) VALUES('rebuild')` | FTS5 есть не на всех прошивках, `rebuild` безопасно пересобирает индекс |
| `CapacitorHttp.enabled = true` | у holychords.pro нет CORS-заголовков, обычный fetch из WebView блокируется |
| sha256 обязателен при наличии в манифесте | защита от битой загрузки и подмены файла |
| Дельта собирается по хэшу текста | хэш считается из `key + text`, правка одной строки даёт новый хэш |
