# План (утверждён 26.10.2026)

## Решения

| Вопрос | Решение |
|---|---|
| Права | Личное приложение, не публикуется. Датасет — сменный пакет |
| База | Только русские песни: `/lang/2`, ≈43 152 песни |
| Аудио / ноты / презентации | Не включаем |
| Язык интерфейса | Русский |
| Стек | TypeScript + Vite → Capacitor 6 → APK; нативный SQLite + FTS4 |
| minSdk / targetSdk | 23 (Android 6.0) / 35, universal APK (arm64 + armeabi-v7a) |
| Планшеты | Адаптив: `<600dp` телефон, `600–840dp` 7–8", `≥840dp` 10"+ с master-detail |
| Обновления | GitHub Releases (`manifest.json` + дельта-пакеты) + режим «новые песни с сайта» |
| Проверка | Эмуляторы (Mac Apple Silicon): API 24 телефон, API 30, планшет 7" API 26, планшет 10" API 34 |

## Источник данных (проверено на сайте)

- URL песни: `https://holychords.pro/<id>`, нумерация почти плотная.
- Текст с аккордами: `<pre id="music_text" class="Ab">` — аккорды отдельными строками над словами,
  выравнивание пробелами. `class` = тональность песни (встречается немецкое `H` = си).
- Транспонирование на сайте — клиентское, сервер не участвует.
- Список русских песен: `/lang/2?page=N` по 50 id (≈865 страниц). Язык на странице песни не маркируется.
- Объём: средний текст 1,3–2,5 КБ; БД ru ≈110–130 МБ, архив ≈25 МБ.

## Этапы

| Этап | Содержание | Оценка |
|---|---|---|

| M6 | Онлайн-обновление базы | 1 дн |
| M7 | Приёмка | 0,5 дн |

## Критерии приёмки

- Авиарежим: все экраны работают, ноль сетевых запросов.
- Автосверка 100 случайных песен с сайтом: текст и исходная тональность совпадают.
- `transpose(+12)` возвращает исходный текст на всей базе.
- Поиск < 100 мс, холодный старт < 3 с после первой распаковки.
- Обрыв сети посреди обновления не портит базу.
- Телефон API 24/30 и планшеты 7"/10"/13", ландшафт: без горизонтального скролла,
  транспозиция и автоскролл не сбрасываются при повороте.
